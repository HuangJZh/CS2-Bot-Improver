# 人类瞄准模型：第一版

目标定位：Low 普通玩家、Medium 普通高手、High 接近但稍逊于职业选手。它们是待实战校准的游戏参数，不是已验证的真人段位或生理指标。

## 依据

采用用户粘贴文章中的连贯甩枪、早期调节与后期修正、延迟观察与运动预测思想。核对论文：https://doi.org/10.1016/j.neubiorev.2016.11.016 。不采用“微调训练完全无法迁移”等未经该研究证明的绝对结论。Google 文档分享链接和文本导出均未能读取，未声称已采纳其正文。

## 三档起始参数

| 参数 | Low | Medium | High |
|---|---|---|---|
| 基础反应 | 200 ms | 170 ms | 130 ms |
| 观察传入延迟 | 90 ms | 65 ms | 45 ms |
| 观察采样间隔 | 50 ms | 35 ms | 25 ms |
| 基础甩枪时间 | 155 ms | 125 ms | 95 ms |
| 基础落点误差尺度 | 0.32° | 0.16° | 0.07° |
| 跟枪平滑时间 | 105 ms | 70 ms | 45 ms |

甩枪耗时随角度和目标角大小增加；准星已在目标附近时，只需很短的运动。反应与观察并非简单逐项相加：反应时间以首次观察时刻起算。实际开枪还受引擎视角平滑、原有开枪判断和武器状态影响。

## 行为

- 每次视觉采样进入延迟队列。纯模型只接收样本，不接触游戏实体。
- 一次规划的甩枪使用平滑曲线和持续的落点误差。早期小幅调整只参考延迟样本，不每帧锁定真实坐标。
- 开火不要求逐次“停下确认、微调”。甩枪进入预计末段即可解除自有开火限制，由原生武器逻辑决定实际射击。
- 跟枪使用观察速度估计和最多 140 ms 的外推；突然反向后有滞后。
- 超出视野、遮挡、烟雾和致盲时不采集新精确坐标。约 200 ms 后模型记忆失效，350 ms 后交还原生搜索；搜索期间仍限制对不可见目标开火，重新看见后重新规划。
- 只接管机器人持枪瞄准；真人、玩家接管、外部视角锁、录像回放、投掷不接管。
- 在 PickNewAimSpot 与 UpdateLookAngles 两处阻止旧插件恢复完美目标点。保留原生后坐力、视角平滑及导航搜索；本版本并未完整替换引擎感知系统，原生搜索转向仍可能与真人不同。
- 原生视角平滑会使最终视角轨迹与模型规划轨迹有差别，需要实战观察；测试通过不代表实战强度达到所述水平。

## 使用和回退

原面板继续切换 Low/Medium/High，开局读取实际难度包。

控制台 `bot_human_aim status` 查看状态，`bot_human_aim off` 暂停新模型并恢复旧瞄准，`bot_human_aim on` 启用，`bot_human_aim reload` 重读配置。命令仅本地服务器控制台可修改。

插件目录 human-aim.json：Enabled 开关、HorizontalFieldOfView 默认110°、Diagnostics 默认false。打开 Diagnostics 后每10秒记录阶段计数，可用于确认是否真正接入。

编译需本机 CounterStrikeSharpApiPath 和其相邻 shared/BotControllerApi/BotControllerApi.dll，或在开发机提供同布局的 API 目录。

验证：纯模型确定性场景测试、原烟雾几何测试、编译、本机 server.dll 签名唯一性检查。游戏内加载和对局表现单独记录，不能用纯模型测试代替。

## 2026-10-31：实际输出验证与直控实验

已增加`bot_aim_capture`采集，记录规划/实际视角、原生目标字段、阶段、开火/伤害/死亡。受控场景显示仅写TargetSpot时，规划变化不保证被当前原生状态执行；因此旧阶段计数不能证明最终动作已经拟合。

新增`DirectViewControl`，默认false。仅在本机专用测试服务器实验启用，恢复后配置仍关闭。它使用已安装BotController所用的SetEyeAngles接口，并修正UpdateLookAngles的单参数原型；不会用传送接口修改正式瞄准。

直控测试中记录视角跟随规划，并产生一条开火、伤害、死亡链路。该场景的目标位置、感知句柄和攻击输入均为脚本控制，不是自然对局。直控绕过原生最终视角路径，原生压枪补偿不能再假定被完整保留；需要后续单独验证和建模，当前不要作为完成版本启用。

## 2026-10-31：开火抑制修复（human.8.4）

8.3“没有有效计划就保持禁止开火”的自然对局实测会让Bot长时间不开火：自然10v10中约97.5%的原生攻击意图被抑制，主要来自尚无视觉样本却被判为`weapon-changed`、`not-visible`和无计划状态。8.4改为：只有存在活动视觉计划（当前pawn/目标/武器、未过期观察、有模型目标点）时才允许暂时抑制开火；无计划、无观察、不可见、目标/武器变化或计划过期时立即释放，由原生Bot决定开火。计划内抑制按难度限制为`反应+甩枪+0.25秒`，超时后保持释放直到模型重新对齐；释放抑制时先撤销令牌再删除记录，未确认的撤销会短暂重试。

这不是恢复“完美原生瞄准”：模型有样本时仍接管目标点和开火时机；但没有样本时会回退到原生瞄准与开火，因此首次接敌的部分“计划前开火”防护被撤回。实测：受控近距离AK/M4场景8秒49次开火、88.3%攻击帧获准；自然10v10步枪局35秒193次开火、17个Bot均有开火。模型检查56项通过，编译0警告0错误。压枪、准备动作、三档校准和独立实战验收仍未完成，不能把本轮结果当作最终强度验收。

## 2026-10-31：移动目标预测、接敌反应与自然距离容许度（human.8.5）

自然对局证据显示8.4的开火容许度在常见距离（约1000单位）只有约0.17°，远小于模型自身约0.86°的对齐误差，模型允许率仅约2%。8.5的改动：

- 预测加入弹丸飞行时间（按武器类别1500–3500单位/秒的假设值）作为移动目标前导；跟踪控制加入期望方位角速度前馈，减少常速目标跟踪滞后。
- 开火容许度改为按目标角半径、武器类别、定位不确定度与MotorError计算，下限0.25°、上限4°；参数为待标定假设。
- 接敌准备第一版：初始准星缺口<10°按“准备接敌”加快反应，>45°按“意外接敌”增加反应与轻微惊吓延迟。
- 原生enemy句柄短暂闪烁时保留最多0.5秒记忆计划，避免频繁重置。
- 新增遥测：敌方世界坐标/速度（仅分析用）、接敌缺口/类别、计划开始/时长、采样失败原因。

专用服验证：62项模型检查、0警告0错误；自然10v10三轮采集合计466发、109次伤害（伤害/射击.234，8.4基线.223，差异不显著），模型允许攻击帧占比从2%升到11.5%–31%；受控静止接触46发/8秒、允许帧84.6%。采样失败仍以“原生可见但精确部位射线失败”为主（约26%），是下一轮首要缺口；容许度/接敌反应未按三档标定，压枪与完整准备状态仍未完成，不能据此宣称强度验收。

## 2026-10-31：部分掩体扇形回退采样（human.8.6）

上一轮证据显示，部分掩体只露出肩/臂/腿时固定优先瞄准点会全部被遮挡，模型拿不到样本（8.5一局约30.8%的可见作战帧未采样），该接触的瞄准和开火时机便回退给原生AI。8.6在固定点全部失败后增加受限扇形回退：沿敌人身体剖面取高度0.4–0.95、横向0–±10的25个候选点，每个点仍须通过视场、无遮挡射线与烟雾门控才可采样，不会穿墙取目标坐标。遥测新增`sample_attempts`、`sample_point`，并把采样结果细化为 base/fan 部位与失败计数（ray/fov/smoke）。

专用服两局自然10v10（各35秒）：A局217发/51伤、模型允许1,177 tick，A局可见作战帧采样率96.1%（8.5同口径约69.2%）；B局196发/40伤、允许652 tick，未采样主要来自烟雾与残余射线失败。62项模型检查通过，0警告0错误。扇形回退不改变视觉误差、开火容许度与抑制规则；烟雾期间的信息边界、残余射线失败和逐tick执行时序仍是后续工作，不能据此宣称强度验收。

## 2026-10-31：短时丢失后的计划保留与回退代价（human.8.7）

独立复核显示，同一次交战中敌人短暂消失再出现时，旧逻辑在0.5秒左右就会丢弃模型、重建计划，重新付出感知间隔+反应+甩枪时间；这比“再多采样点”造成的损失更大。8.7改为：同一敌人、同一pawn的短时可见性丢失后，只要重新出现时距上次可见不超过1.0秒，就继续使用原计划并送入新样本（人类重新探头通常继承原预瞄与运动意图）；超过1.0秒、换敌人或换pawn才重置。遥测新增`model_lifecycle`事件（keep/reset）与丢失时长。同时把回退采样候选裁剪为25点、烟雾检查提前到射线之前以降低失败代价，身体回退点使用0.985射线阈值（头颈/下颌保持0.999），并新增`sample_ray_fraction`。

专用服验证：8.7两局自然10v10（各35秒）分别219发/59伤（伤害/射击.269）与158发/57伤（.361），模型允许tick 559/568；C局生命周期保留11次、重置2次（8.5同口径重置9–15次），相当于回收约4秒以上模型可用窗口。未采样仍主要来自烟雾和残余射线失败，二者与permission latch/执行时序一样留待后续；样本小且对局不同，不能当作命中率或强度验收。

## 2026-10-31：烟雾信息边界的降级采样（human.8.8）

烟雾挡住所有精确采样点时，旧逻辑会让模型失去样本、把开火与瞄准交还原生AI，而原生瞄准不受烟雾限制，等于穿烟完美瞄准。8.8改为“模糊看到”的降级信息：目标被原生判定可见、但精确点都被烟雾挡住时，按烟雾几何误差（35–100单位，与距离相关）生成一个粗略身体采样点，并附加0.6°不确定度，再进入正常的感知延迟、视觉误差和运动规划。模型因此按模糊信念瞄准/开火，开火容许度因不确定度升高而收紧，而不是精确穿烟；完全被墙挡住且无烟时不会生成该样本。

专用服3局自然10v10（各35秒，`bot_nades max`制造烟雾）：smoke-degraded状态行分别57/317/505（占0.5%/7.4%/21.8%），降级窗口内枪械射击/命中为2/0、22/2、38/12，整体命中/射击0.096/0.18/0.278；样本小、伤害多为燃烧瓶/手雷，不能据此声称混烟精度已下降或校准完成。烟雾遮挡的回放核验、偏移与不确定度标定、permission latch、punch/后坐力感知与完整准备状态仍是后续工作。

## 2026-10-31：权限闭锁与短时记忆预瞄（human.8.9）

此前模型允许开火的窗口往往只有2–13 tick，连发/跟枪时门控反复释放—重握，每次重握都会重新施加Attack抑制并制造释放边沿；目标短暂回掩体时模型又立刻把瞄准交还原生搜索。8.9增加：

- 模型允许开火后，在同一次计划内保持150毫秒允许闭锁；只有目标/武器/可见性/观察新鲜度检查都通过才生效，不会延长不可见或过期观察后的权限。遥测记录`allow_latch_active`与`allow-latch`原因。
- 目标暂时不可见但视觉记忆未过期（≤1.0秒）时，继续按记忆/预测角度维持模型预瞄，不再立即交还原生搜索；超过1.0秒、换敌人或换pawn才恢复。

专用服3局自然10v10（各35秒）：允许开火窗口中位29–48 tick、p90 64–108 tick（此前常见2–13 tick）；57%–71%的枪械射击发生在闭锁窗口内；memory_aim行约占观测行0.9%–5.3%；生命周期的keep/reset仍以keep为主。三局命中/射击.182/.348/.277，与上一轮同量级，样本小且对局不同，不能当作命中率或强度验收。闭锁可能导致最多150毫秒的滞后放开、记忆预瞄质量、post-suppression Attack位、punch/RCS、完整准备状态与三档校准仍待后续验证。

## 2026-10-31：执行层闭环试验（human.8.10→8.12，负结果已回退）

目标要求实际视角闭环。测量后得到明确的负结果：

- 把实际准星误差混入开火判定（8.10）：自然对局实际准星误差中位约3–6°、p90 10–31°，而开火容许度约0.5°，导致计划已对齐的帧有78%–95%被否决，模型开火被压制并由hold-timeout回退原生AI，已回退。
- 把实际-计划误差注入TargetSpot（8.11）：planned-vs-actual误差反而从约3–4°中位恶化到7–9°中位、p90最高142°，原生视角平滑被更远的点带偏，已回退。
- 8.12恢复8.9开火/瞄准行为，仅保留`fire_actual_error_degrees`、`aim_feedback_correction_degrees`、planned-vs-actual测量。两局验证planned-vs-actual中位2.54/3.86°，允许开火与闭锁窗口正常，命中/射击.145/.153（与之前同量级，样本小）。

受控AK近距连射37发命中36发但只有1–4发短点射，未验证远距离长连发/压枪。结论：在执行层（原生视角与计划的中位约3°差距）解决前，用实际视角做开火闭环或目标点闭环都不可取。RCS与真正的执行闭环需要可靠的长距离试验场景和已验证的执行器，仍是后续工作。

## 2026-10-31：压枪补偿第一次尝试（human.8.13→8.14，负结果已回退）

用600单位长距离fixture做A/B：8.12基线44发21中（.477）；8.13按爆发中“实际视角与计划的pitch差”做比例下压补偿（增益.30/.50/.70），结果43发仅9中（.209），补偿值中位-2.43°、第4发后全部脱靶。判断是引擎实际视角已包含原生向下补偿，模型再修正会过冲；同时第一版有pitch符号错误导致补偿恒0。8.14回退补偿注入、只保留爆发跟踪与补偿遥测，等待逐发弹道方向/命中位置真值后再重做RCS。
