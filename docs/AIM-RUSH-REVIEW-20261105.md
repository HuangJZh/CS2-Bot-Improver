## 值得借鉴的部分

### 1. 保留真正的原生对照，减少重复控制

原版未另写一套瞄准控制器。我们现在有模型轨迹、原生视角、声音关注、地图预瞄等多个层次，近期已实际发生控制竞争。因此最有价值的参考是做同一场景的原生基线，逐项确认额外覆盖是否改善了首枪、跟踪、声音转向和交战连续性。

注意：我们当前的 `bot_human_aim off` 不是完全原生。拟人层关闭后，PickNewAimSpot 的旧部位选择仍会工作；BotState、BotSupport 等模块也继续修改行为。真正原生对照需要隔离这些覆盖，或增加可核验的原生模式。

当前瞄准插件也没有只限官方爆破图运行的条件。如果沿用带插件的启动方式打开 Aim Rush，它同样可能介入；此时不能将体验全部归于原版地图。

### 2. 地图约束优先于全图随机补救

NONAV 标记证明作者使用了局部导航生成约束。可借鉴为官方地图中经过记录验证的坏点、异常连通边和不合理路线提供地图级修正，而不是不断增加随机跳跃、横移或传送补救。

我们现有团队图导出主要保留区域、角点、质心和连接，未完整保留所有原生导航语义。后续可检查语义是否可读、是否影响执行，再考虑保留或追加局部约束；不能据此断言现有图一定含错误路径，因为 NONAV 区域本来可能已经不在原始导航图内。

### 3. 纯枪、对称装备和高接敌密度的验证环境

关闭道具、统一经济/护甲和武器，适合分开测试枪法、移动与射击的配合。建议建立可恢复的诊断预设，固定距离与武器，再比较看到目标至首次有效开火、移动首发、丢失目标后的恢复、不同角差的定位和多目标转移。

该建议来自地图的控制变量设计。它不证明 Aim Rush 的瞄准算法更优，也不能把训练场的战绩直接映射到 5v5 爆破难度。紧凑场地和出生布置可能增加交战密度、改变难度体感，这部分仍需实测。

### 4. 清晰的装备槽检查和集中设置

回合开始时先检查实体、库存和空槽，再补装备，是清晰的状态校验范例。我们已有资金、库存和道具消费约束，主要可用它补充回归场景；不应重复实现或照搬原版给所有玩家补手枪的规则。
