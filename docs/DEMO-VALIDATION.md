## 主要发现

1. **声音反应偏“机械”**：职业选手听到枪声后 0.375 秒内的“转身对准”比例只有 6–13%，多数情况是原本就对准或继续架枪。我们目前对范围内、无可见敌人的 Bot **每次枪声/脚步都转向**，比职业选手更敏感、更确定。  
   建议：给声音预瞄增加“注意力概率/冷却”（例如 30–50% 概率才转向，或正在架枪时不打断），而不是无条件覆盖。  
   注意：demo 指标只统计“转身”，职业选手可能用后退/横移/提前枪响应，因此 6–13% 不是“听到比例”，但足以说明“不是每次都转”。

2. **头部优先的瞄准方向是对的**：职业爆头击杀率 51%，AK 62%，与我们的 HEAD/NECK/JAW 优先级一致；命中部位以胸腹为主，说明模型误差/散布应保留（不能用完美头部锁定）。

3. **静音参数基本对齐 demo**：残局 28%/0.6–3.0s 的稳态约 26% walk，接近实测 22.6%；同行约 4% vs 实测 3.5%。控图静音仍略高于职业开局实测（职业 20 秒内几乎 0%），可以后续再压低。

4. **地图搜点职责、忘记搜点、严格道具、只露头挡墙、预瞄横移** 都没有可直接从职业 demo 提取的标签/事件；这些只能靠服务端日志与游戏内遥测校验，不能声称“demo 已验证”。

## 结论

- 已用 demo 直接校验：**爆头/命中分布（方向一致）**、**静音概率与时长（近似一致）**、**声音反应率（我们偏敏感）**。
- 无法用 demo 直接校验的机制：地图搜点/职责/忘搜、严格购买投掷、只露头挡墙、横移、原生听觉补丁——这些需要游戏内遥测或服务端日志，不能算通过。
