# Custom 8.51：保持行为的第一轮性能优化

## 修改范围

- BotAimImprover 将同一 tick 内的玩家实体发现合并为一次；实体创建、生成、删除和地图切换立即使缓存失效。缓存只有控制器列表，没有缓存位置、存活状态、视角或可见性。仍使用实体列表，兼容 BotHider，不依赖菜单阶段可能过期的 Server.MaxPlayers。
- 听觉的敌人优先检查保持原有稳定顺序，移除每次排序和头/胸候选数组分配。烟雾检查移除捕获闭包。
- 一次同步人体采样只读取一次目标位置、蹲姿高度和朝向，复用旋转计算；没有跨帧复用坐标，也没有省略候选点、视线或烟雾检查。
- 三档不可变瞄准配置复用实例；维护循环利用 .NET 10 支持的遍历中删除，移除高频临时字典快照。
- 导航区域采用 256 单位的空间索引；保留原来的高度限制、包含优先、最近距离、距离上限和同分顺序。超大或异常地图退回线性搜索，并限制索引内存预算。
- BotState 复用闪光弹临时列表的容量，列表内容每 tick 重新采样。

未修改：难度数值、敌我强度、视觉/声音采样频率、转身与开火门控、MIX/HEAD 意图、弹道、地图路径边、补枪及道具决策。原生机器人、碰撞、动画、导航和渲染本身的成本仍然存在。

## 验证

- `tools/performance-checks`：34,149 项检查，包括缓存失效/同 tick 槽位替换/计时回退/失败重试、10,000 组目标坐标变换、导航边界/楼层/同分/异常回退，以及十张地图对旧 Locate 实现的逐点对照。
- 原有模型 236 项、导航 32 项、混烟 7 项、姿态 12 项检查通过。两个插件 Release 构建通过，仅有原有 ConVar 弃用警告。
- 离线导航基准原始数据见同目录 `PERFORMANCE-20261111.json`；每张地图 2,400 次查询，经预热后计时，原算法和新算法的返回校验和一致。这里测量的是 Locate 方法，不能换算成整局 FPS 或插件整体 CPU 的同比改善。
- 新 Locate 在基准查询中没有临时托管分配；原方法每张地图约产生 1.25–1.32 MB 的临时分配。索引在载入地图时一次构建，以少量常驻内存换取重复搜索速度。
- 离线 Locate 用时为旧算法的约 3.3%–12.9%，各地图各 2,400 次查询；这是特定工作负载下的局部结果。
- 回环专用服务器 Dust2 加载验证：10 个机器人均移动，采集 21 次开火、18 次伤害和 3 次死亡事件；模型状态 active=True、native_ready=True，没有新增插件异常。此测试检查加载及基本运行，不是完整对局行为等价证明或客户端帧率测试。临时探针已移出游戏，测试挂载逐字节恢复。
- 安装文件与数据共 511 项哈希核验；面板单独按桌面快捷方式指向的位置检查。

## 安装与回退

仅替换 BotAimImprover / BotState 的 DLL、PDB、deps.json；保留配置、道具快照、预瞄数据、导航图和其他插件。

安装前完整备份位于 `D:/codespace/CS2-Bot-Improver-backups/performance-20261111/before`。回退时在 CS2 退出后恢复这两个插件目录中的对应文件即可。运行状态测试和 FPS 测量应分开：专用服务器没有客户端渲染，不能据其加载或交战结果宣称恢复了 300 FPS。
