# 购买优先级（2026-11-01）

安装版本：NadeSystem inventory.3、BotSupport 1.0.5。

1. 先让现有 BotBuy 完成自己的枪械购买。检查已安装版本，其自购和自动发枪计时分别在开局前几秒、约第 2 秒执行；本次未替换 BotBuy 或改动其武器偏好。
2. 开局前 4 秒收到的轮盘要枪请求先排队，到第 4 秒后重新检查购买区、存活、主武器、余额和队友资格，再发枪。仍由余额最多的合格 Bot 出钱，保留 AWP/AK/M4 随机与买不起时的原有降档规则。死亡/换 pawn、断线、换回合或回合结束不会把旧请求带入新局。
3. 道具最早在开局第 5 秒购买。任何入口，包括冻结结束事件与购买重试，都受这一限制。没有主武器的 Bot 不先花钱买道具；真正低预算的手枪局允许用手枪/护甲之后的余额买道具。
4. 同队有存活真人还在购买区且没有主武器时，同队 Bot 暂缓买道具，留钱等其要枪。真人买到/收到枪或离开购买区后，再用剩余资金买道具。购买窗口内继续检查，取消原有任意 14 秒截止，以兼容正常冻结时间与较晚的要枪请求。
