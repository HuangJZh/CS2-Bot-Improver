# 8.41：轻量回合反馈学习（2026-11-02）

新增奖励/惩罚驱动的局内区域记忆，属于 RL 风格的轻量自适应规则，不是训练神经网络或完整 Q-learning 战术系统。

## 行为

- **防守道具**：CT 记录己方战斗死亡区域。下一回合，附近已有且可用的烟、闪、雷、火快照优先排序；烟闪原有概率再乘区域系数。失败区域相对更受重视，其他区域适度降低倾向，从原有总量中改变分配。
- **进攻换路**：T 记录实际经过的区域及己方战斗死亡。失败回合增加这些区域的路线成本，成功复用则降低旧惩罚。下一回合 A* 在已有可达路线中倾向绕开受挫区域。
- **遗忘与探索**：每回合旧值乘 0.65；每个模块保留 20% 概率不使用学习偏置，继续原有策略。单次失败不能永久封死一条路。
- **作用时机**：当前回合只收集，回合结束后才更新；不会死一人就立刻精确反投。赢下回合但有伤亡时也留下较弱记忆。

路线与道具模块各自使用同一份纯策略源码维护本地记忆，不需要共享进程外服务。CT 的道具记忆只由战斗死亡产生，普通布防行走不算失守。学习输入只有己方位置、实际通行及回合结果，没有加入隐藏敌人的当前坐标。

## 限制与参数

记忆按阵营及 320×320×64 单位区域存储，查询还检查实际高度差，避免将上下楼层混为一处。损失回合的死亡最多给区域增加 0.50×计数（计数上限 3）；赢局伤亡为 0.12×计数。失败通行区域增加 0.10，成功复用减去 0.18。值在 0–1 内，每张地图最多保留 512 个区域。

CT 烟闪的概率乘数为 0.85+0.40×区域风险，最后限制在 0–1。排序只调整普通烟闪雷火，原有诱饵/特殊条目位置保留。没有新增道具、库存、购买资金或队伍投掷额度，也没有绕过快照触发位置、原情报/目标判断、友军保护、冷却和原有资格检查。没有快照、没有库存或原判断不允许时，不会为了学习强扔。

路线仍受最短路 1.4 倍加 64 单位的绕路上限约束；没有可行替代路线时可以继续原路。导航没有覆盖到的路段不会伪称已实际经过。既有交战、紧迫下拆包和原生脱困优先级保留。

记忆仅在当前游戏进程内使用；换图、重启游戏或识别到换边时清空，不把旧对手的阵营经验转给新队伍。手动清空命令为 `bot_route_learning reset`、`bot_nade_learning reset`；对应 `off/on/status` 控制应用和查看状态。本地主机或服务器控制台可用，普通远程玩家不能修改。

路线设置 `human-aim.json` 的可选 `RoundLearning` 默认 true；道具模块缺省启用。瞄准参数、队友 0.85 和敌方强化系数不变。

## 验证

21 项共享策略检查通过：回合内不即时反应、失败防守改变后续投掷排序、己方记忆隔离、楼层隔离、遗忘、成功复用、重复结束不重复训练、无效输入、内存上限、换边清理、进攻失败后确实可选择其他走廊、探索保持原排序及绕路上限。

另有 32 项十图导航检查、173 项瞄准检查、8 项购买策略检查通过。BotAimImprover 与 NadeSystem 构建均零警告零错误。

运行证据、原始采集和安装校验位于 `E:/csdemo/bot-captures/round-learning-8.41-20261102`。先用短回合验证了三轮更新与历史成本读入；由于短回合不足 25 秒，会触发既有紧迫任务回退，该段不作为行走改进证据。随后以正常可执行导航的回合时长继续回归，结果单独保存在 `normal-runtime`。

后续 Dust2 回归使用 60 秒回合、20 秒 C4 和 1 秒冻结，只用于自建回环进程；没有攻击、位置或感知注入。五段采集包含 361 条实际路线步进、29 个路线计划，计划中的学习轮数由 0 推进至 2，其中 8 个 T 进攻计划读取了非零历史成本，最大平均区域风险约 0.256。记录有 185 次开火、66 次伤害、18 次 Bot 击杀。NadeSystem 的日志也记录到了上一轮防守伤亡区域的候选优先级，分数约 0.091；这是候选排序被应用的证据，不是该点实际投掷数量增加的统计。最终测试进程退出，临时测试插件移出，gameinfo 恢复。

本版的“更多投到失守点”和“换进攻路”都是概率偏好，不保证每回合一定发生，也没有以短样本证明胜率提升。未观察到的实机分支不能用纯策略测试冒充完整比赛验收。
